# 知行教研（SC 学情诊断系统）

知行教研是一套面向中学教师的学情诊断工具。它把考试或练习结果整理成可追溯的知识点分析，帮助教师快速回答三件事：

- 哪些知识点需要关注？
- 学生可能卡在哪里？
- 下一步应该怎样补学，并如何通过复测确认效果？

系统当前以初一数学为试点，知识库可按学校的教材和学科继续扩展。

## 产品能做什么

1. **收集成绩与作答信息**：支持手工录入、Excel 导入和拍照录入。
2. **生成班级分析**：查看整体掌握情况、共性薄弱点和教学建议。
3. **生成学生诊断单**：按学生查看薄弱知识点、证据和下一步建议。
4. **支持教师复核**：重要标注和归因都可以审核、修改或否决。
5. **形成干预闭环**：记录补学行动，复测后查看掌握度是否改善。
6. **可选 AI 辅助**：用于试卷解析和文字整理；没有模型配置时，系统仍可使用确定性分析和模板报告。

SC 的输出是辅助教学决策的证据和建议，不替代教师判断，也不用于推断学生的家庭、动机或心理状态。

## 快速启动（本地开发）

### 环境要求

- Python 3.11+
- Node.js 20+
- npm

### 1. 启动后端

```bash
cd backend
python -m venv .venv

# macOS / Linux
source .venv/bin/activate

# Windows PowerShell
# .venv\Scripts\Activate.ps1

pip install -e .
python -m uvicorn app.main:app --reload --port 8000
```

后端启动后可访问 <http://127.0.0.1:8000/docs> 查看接口文档。

### 2. 启动教师端

另开一个终端：

```bash
cd frontend/app
npm install
npm run dev
```

打开 <http://127.0.0.1:5173>。

### 3. （可选）启动产品官网

```bash
cd frontend/site
npm install
npm run dev
```

官网地址为 <http://127.0.0.1:5174>。

### 4. 导入示例知识库

首次使用可以导入仓库内置的初一数学知识库：

```bash
curl -X POST http://127.0.0.1:8000/kb/import \
  -H "Content-Type: application/json" \
  -d '{"yaml_path":"kb/math/grade7/kb.yaml"}'
```

然后在教师端创建学校、班级和考试，按页面提示录入或导入数据即可。

## 使用真实模型（可选）

复制配置模板：

```bash
cp backend/.env.example backend/.env
```

在 `backend/.env` 中填写模型供应商和密钥，例如 `SC_LLM_PROVIDER`、`SC_LLM_API_KEY`、`SC_LLM_BASE_URL` 和 `SC_LLM_MODEL`。不配置密钥时，涉及模型的功能会降级或提示配置，不影响基础数据管理和确定性分析。

## Docker 部署

适合试点或长期运行时使用 Docker Compose：

```bash
cp backend/.env.example backend/.env
cd deploy
docker compose up -d --build
```

默认入口：

- 官网：<http://127.0.0.1:5174>
- 教师端：<http://127.0.0.1:8080>
- 后端文档：<http://127.0.0.1:8000/docs>

完整的环境变量、备份恢复和升级说明见 [DEPLOY.md](DEPLOY.md)。如果是全新环境且 `gateway/.runtime/` 不存在，需要先按部署文档准备运行时文件。

# 运行后端测试

## 录入、诊断与复测闭环

- **录入质量预检**：考试工作区的「提交」页检查漏题、越界分数、学生归属和总分一致性；可直接补录或更正得分。低于 60% 把握的得分必须先人工核对，其他提醒需教师确认。Excel 原始质量提醒保留至提交前，不因关闭导入页丢失。
- **诊断依据**：学生诊断页的「查看诊断依据」按评估日期分页展示已提交作答的题目、得分、来源和衰减后权重，可跳转原考试报告。
- **十五分钟行动卡**：行动明细提供六类干预的 3/5/5/2 分钟教学步骤和本班原题参考；使用确定性模板，不调用模型生成题目。
- **复测安排**：确认干预时默认排在执行后 7 天，可指定或调整到今天至未来 90 天。班级诊断单显示待复测、已到期和已有复测证据；只有执行后、截至当前时点的同知识点已提交证据才计入验证，获得证据不等于掌握度改善。全班进度按当前名册统计，历史干预不自动补日期。

新版本启动时会补充 `intervention.retest_due_date` 和 `exam_response.source_warnings_json`；启用 Alembic 的部署执行迁移链，默认部署走幂等增量迁移。

## 今日任务与诊断小题组

- **教师今日工作台**：班级首页汇总本班当前学科全部考试的作答审核、标注审核、报告签发、教学行动和复测任务，支持分页。今天及逾期复测优先显示；小组行动合并成一项。
- **最小补证据任务**：学生诊断页单列已学但数据不足的知识点，按证据缺口预览最多 3 道检查题；不是直接判为薄弱或安排大量练习。
- **归因验证题组**：展开「可能的原因」后预览前置基础、目标应用或易混概念的对照检查题。遗忘假设仍需间隔复测，小题组不自动确认原因。
- **题源与建卷**：只选本班当前知识库中已有、已审核、单知识点的题目，排除该生已作答及同题干题目。题源不足明确显示缺口，教师核对完整题面、答案和适用性后建诊断卷，继续走标注审核、采集、质量预检和提交。建卷不会自动派发或产生作答证据。
- **学生下一步任务卡**：学生门户最多呈现 3 个关注点，说明学习原因、步骤、约 10 分钟的安排和完成标准，链接现有学习方案。自报进度不改变掌握度；管理员预览同源只读，不生成方案。

这批功能复用现有考试与学习记录，无新增依赖或数据库迁移。
