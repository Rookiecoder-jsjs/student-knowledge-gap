## 1. V1 · 金标集循环验证，绕开最难的环节

### 现状（代码实证）

`simulator/synthetic.py` 生成数据的两条关键路径：

```python
# :172 每题只挂一个知识点
"kps": [{"code": code, "weight": 1.0}]

# :217-221 分数由真值掌握度 + 小噪声生成
m = true_mastery(alias, code, exam_date)
p = m + (0.5 - tq.difficulty_est) * 0.2 + rng.gauss(0, 0.05)
```

而管线掌握度 `mastery_of_events`（`mastery.py:82`）是这些分数的**加权平均**。于是「薄弱召回 0.80 / 根源命中 0.96」测的是：**对一组围绕真值波动的样本取加权平均，能否还原真值**--这是统计常识，不是模型能力。

三个真实误差源在金标里全部缺席：
1. **失分归属**：每题单 kp，`EVIDENCE_MIX_PENALTY`（§1.4-C 改进）既不测试也默认关闭。README 自承的「物理上限」在金标里是 0 误差。
2. **标注误差**：模板用 `kp_rows[code]` 直接挂正确标签（`synthetic.py:159-174`），即标注 100% 正确。而 README 自承端到端仅 60-70%，主因即 LLM 标注。
3. **图谱误差**：植入集合（`GROUP_A` 等）按图谱前置链定义，归因也走同一条链（`attribution._prereq_deficit` 沿 `graph.prerequisite_chain`）。测的是「算法按植好的路走对」，不是「在真实图谱上找对因」。

### 方案

**A. 压力金标集（代码 now）** -- `simulator/test_stress_gold.py`，四个**诚实度量**场景，断言只设宽松 sanity 下限，真实数字打印输出，让测试成为测量仪器而非拉拉队：

| 场景 | 注入 | 度量 | 预期发现 |
|---|---|---|---|
| S1 多kp污染 | 强kp+弱kp的混合题，弱kp拉低混合题分 | 强kp掌握度在 MIX_PENALTY on/off 下的偏移、是否被误判薄弱 | MIX_PENALTY 减弱污染（方向性断言） |
| S2 标注错误 | 按 rate p 把题目标注改到错误kp | p=0/0.1/0.3 下薄弱召回与误报曲线 | 召回随 p 单调下降，量化真实精度衰减 |
| S3 图谱扰动 | 删除植入根源所在前置边 | 根源命中率下降幅度；`suspect_edges` 是否捕获 | 归因对错边敏感；审计部分可观测 |
| S4 全局薄弱 | 植入 base_ability=0.4 的全弱学生 | 前置缺陷归因条数、置信度、相异根源数 | 过度归因（与 V3 抑制器对照） |

**B. 真实人工金标（人工 later，阻塞对外宣称精度）** -- 200 题教师标注真实失分归属。**无此项，0.80/0.96 不可对外当精度讲。** 这是第一优先级的人工任务，比任何新功能都重要。

### 验收
- 压力金标 4 场景可独立运行，打印真实指标；宽松断言通过（不破坏 118 基线）。
- S1 证明 MIX_PENALTY 方向性有效；S2 给出标注错误率-召回曲线；S3 量化图谱敏感性；S4 暴露过度归因（抑制器落地后缓解）。
- 人工金标路线图与预算列入本文档（§7），即使尚未执行。

## 3. V3 · 归因因果性弱：全局薄弱学生被过度归因

### 现状（代码实证）
`_prereq_deficit`（`attribution.py:94-156`）：学生 kp A 弱 → A 的祖先也低 → 取「缺口×前置强度」最大的祖先当根源，置信度 `min(0.9, 0.6+0.1*len(low_ancestors))`。

问题：**相关≠因果**。一个 base_ability=0.4 的全局薄弱学生，在多数 kp 上都低于底线 → 每个弱点都触发前置缺陷归因 → 每个都指向「某个恰好最低的祖先」→ 产出大量 0.9 置信度的「伪因果」根源主张。置信度机制对「整体薄弱」完全不敏感。

### 方案
**A. 全局薄弱抑制器（代码 now）** -- `run_attribution_for_student` 内：算学生在已覆盖+有证据 kp 中的薄弱占比 `weak_frac`；当 `weak_frac >= GLOBAL_WEAK_RATIO`（默认 0.6）且样本 ≥5，对前置缺陷归因：
- 置信度下调至 `GLOBAL_WEAK_CONF_CAP`（默认 0.5）；
- evidence 追加 `{global_weak: True, weak_fraction, note}`，建议优先排查整体基础/学习状态。

**不删除归因**（仍是待验证假设），只降置信度+标注，避免伪因果高置信。targeted-weak 植入学生（GROUP_A 等，弱 kp 占比低）不受影响 → 金标基线不退化。

**B. 证伪闭环度量（代码 now，见 V3-度量）**：让「可证伪」从纸面承诺变可观测。

**C. 证伪施测率（人工 later）**：诊断题实际施测率需真实教师流程，代码只能度量已发生的验证。

### 验收
- S4 度量：抑制器落地前，全局薄弱学生前置归因条数/均值置信度；落地后下降。
- 既有 101+17 测试全绿（抑制器只影响全局薄弱学生，植入学生 targeted-weak 占比 < 0.6 不触发）。
- 行为测试：全局薄弱学生前置归因置信度 ≤ cap，evidence 含 global_weak 标注。

## 4. V4 · P25 判据结构性误报，与「不排名」张力

### 现状（代码实证）
`weakness.py:177-184`：
```python
below_floor = a.mastery < a.floor                # 绝对底线
below_p25  = a.mastery < a.class_p25             # 班级 P25
if below_floor and below_p25:  "两者"
elif below_floor:              "绝对底线"
elif below_p25:                "班级P25"          # ← 独立判据
```
薄弱 = floor **OR** P25。`below_p25` 按定义约 25% 学生恒满足--**即使全班都好**（全员 0.85，末位 0.80 仍判「班级P25」薄弱）。这是 population 级结构性误报。README 承认误报 0.21，仅在完美标注合成数据上。

更深的张力：设计约束明确「不展示排名（双减）」「成长框架」，但薄弱引擎核心判据之一就是**排名**（P25）。用相对位置判薄弱再把缺口表述为「下一步」，是换了说法的排名。绝对底线可辩护；P25 相对判据把规范性排名塞进了「不排名」产品。

### 方案
- **A. P25 结构性误报度量（代码 now）**：测试打印「全班都达标」场景下 P25 判据的误报率，量化结构性问题。
- **B. 判据修订方案（设计，需产品决策，不擅自改语义）**：三选一--
  1. 收紧为 `below_floor AND below_p25`（只有既低于底线又低于 P25 才判薄弱）--误报大降，但可能漏报「绝对尚可但明显落后」的学生；
  2. P25 判据加绝对缺口门槛（`below_p25 AND mastery < floor + 0.1`）--保留相对落后信号，去掉「全员优秀还报薄弱」；
  3. 移除独立 P25 判据，P25 仅作报告参考不参与薄弱判定--最彻底，但弱化班级参照价值。
  推荐方案 2（config-gated，默认保持现状，试点 `SC_WEAKNESS_MODE=strict` 启用）。
- **C. 不擅自翻转默认**：判据语义影响教师所见，属产品决策。代码落地 config-gated 选项 + 度量，默认不变。

### 验收
- 度量测试打印 P25 结构性误报率（预期 ~25%），文档化张力。
- strict 模式 config-gated 可用，金标基线在默认模式下不退化。

## 5. V5 · 采录摩擦未度量，价值/成本失衡未知

### 现状
拍照路径（差异化楔子）：拍空卷→LLM 解析+标 kp→审全卷标签→**每个学生拍一张**卷面→LLM 抽分→低置信复核→指派→提交。一班 50 人 = 50 张照片+多轮审核。一学期 4-5 次考试 = 200-250 次拍照+审核。归因的边际价值（60-70% 精度、未验证、图谱未审）是否大于此成本，**代码/测试无任何地方度量过**。

### 方案
- **A. 摩擦遥测脚手架（代码 now，部分）**：在采集/审核关键节点用 `observability` 结构化日志记录计数--批量上传 item 数、低置信保留数、抽样复核数、指派未匹配数、commit 派生事件数。让「每次考试教师付出多少」可观测。
- **B. 真实耗时研究（人工 later）**：试点教师计时，对比「省下的讲评准备时间 vs 系统采录耗时」。北极星「干预提升率」要等闭环，但「教师分钟数 saved vs spent」能立刻测，直接回答产品有效性。

### 验收
- 关键采集节点有结构化计数日志（可从日志还原单次考试的教师交互量）。
- 真实耗时研究路线图列入 §7。

### 验收

## 8. 不改动项（显式声明）

1. **四条架构不变量不动**：derive-on-read（不变量②）保留，抑制器只调置信度不存可变快照；closure 端点只读。
2. **不翻转既有默认开关**：V6 只文档化预设，不破坏演示/基线。
3. **不擅自改薄弱判据语义**：V4 只度量+config-gated 选项，默认行为不变。
4. **金标基线不退化**：抑制器只影响全局薄弱学生（弱 kp 占比 ≥0.6），植入学生 targeted-weak 占比低不触发；压力金标为新增独立文件。
5. **不引入真实人工金标之外的新基础设施**：阶段二的人工任务是精度宣称的前提，不可由代码替代。
