## 1. 项目概述

### 问题定义

基于固定年级知识库，长期追踪学生每次考试/练习表现，估计各知识点掌握度，
归因薄弱点的成因，并生成针对性教学干预方案，通过复测形成闭环。

### 产品定位与差异化

市场已有考生（智学网、七天网络、松鼠 AI 等），普遍依赖机读卡/标准化扫描，
输出以"薄弱知识点清单"为主。本系统的差异化楔子：

1. **普通手机拍照/成绩单导入即可**，不要求机读答题卡；
2. **不止薄弱清单，给带证据、可证伪的归因链**（薄弱 ← 前置缺陷 ← 具体根源）。

### 能力边界（对外承诺的边界，必须守住）

- 只诊断**知识维度**：动机、家庭、考试焦虑、师生关系等不可见因素不在诊断范围；
- 所有归因输出定位为"**带证据的方向性假设，供教师确认**"，不是诊断结论；
- 归因精度受标注质量与失分归属的天花板约束（端到端估计六七成），
  产品形态必须与这一精度匹配：证据随行、置信度可见、教师可否决。

## 2. 核心决策总览

| 维度 | 决策 |
|---|---|
| 试点学科 | 数学（单年级起步，年级待定） |
| 知识库 | LLM 起草（课标+教材）→ 教研审核；YAML+Git 版本化；统一图谱跨年级 |
| 数据入口优先级 | ① Excel 成绩单导入（P0）② 分数录入表格 ③ 拍照解析（P1） |
| 知识点标注 | LLM 全量知识库闭集选择 + 教师审核 + 修正日志飞轮 |
| 掌握度模型 | 证据事件实时推导（时间衰减加权），不存储可变快照 |
| 归因 | 规则引擎，多假设并存，可证伪（诊断题验证），教师可否决 |
| 干预 | 规则决策 + LLM 渲染；题目来源 = 题库复用（题族变式） |
| 产品形态 | 教师端为主；第一交付物 = 考后质量分析文档 |
| LLM | 云端 API，provider 无关接口层，预留私有化切换 |
| 北极星指标 | 干预提升率（被干预薄弱点复测后提升超阈值的比例） |

## 3. 总体架构

```
┌──────────┐  ┌──────────────┐  ┌──────────┐  ┌────────┐  ┌────────────┐
│ 知识库层  │→│  数据采集层   │→│ 知识追踪层 │→│ 归因层  │→│  干预层     │
│ 知识图谱  │  │ Excel/拍照→   │  │ 证据事件→ │  │ 假设+  │  │ 方案+题库+ │
│ 版本化   │  │ 审核→提交     │  │ 实时推导  │  │ 证伪   │  │ 复测闭环   │
└──────────┘  └──────────────┘  └──────────┘  └────────┘  └────────────┘
```

### 架构不变量（四条，违反即设计缺陷）

1. **分析层只读已提交数据**
   采集流水线是状态机：`上传 → 解析中 → 待审核 → 已提交`。
   掌握度、归因、报告只能基于"已提交"数据；草稿/待审数据隔离在暂存区。

2. **派生状态只推导、不存储**
   掌握度、归因依据均由不可变的证据事件实时推导（本规模下计算成本可忽略）。
   教师修正标注/分数后，一切下游结果自动正确，不存在陈旧快照。
   仅在导出报告时物化快照留档（`report.snapshot_json`）。

3. **LLM 输出必经闸门**
   任何 LLM 输出进入分析前，必须经过：人工审核，或封闭集合的 Schema 校验。
   LLM 负责解析/标注/渲染，判断权在人与确定性逻辑。

4. **报告数字零幻觉**
   叙述性报告采用模板槽位生成：数字与结论由系统注入，LLM 只写连接性文字。

## 4. 知识库层

### 图谱模型

**统一图谱，年级是节点属性而非分区**（学生纵向跨年级，图谱必须整体演进）。

节点 `knowledge_point`：
- 编码、名称、课标描述、年级/学期、教材版本
- 期望认知层级（识记/理解/应用/综合）
- 难度先验

边 `kp_relation`：
- `prerequisite` 前置依赖（带强度权重，支持跨年级）——归因追溯的基础
- `contains` 章节包含层级
- `confusable` 易混淆点对
- `spiral` 跨年级螺旋演进线（整数除法→分数运算→分式运算）

### 粒度与规模

每科每年级 50~150 个知识点、2~3 层结构。每题标注 1~3 个知识点。

### 构建与维护流程

1. LLM 基于课标+教材目录生成草稿（知识点+关系边），输出 YAML；
2. 教研审核修订（Git 管理，审核通过合并）；
3. 导入脚本写入数据库，生成 `kb_version`；
4. **数据反查图谱**：若某前置边两端掌握度长期无相关性，标记可疑边进入复核队列；
5. 标注修正日志同时反查知识点定义质量（某点标注总被改 → 定义可能模糊）。

### 版本化原则（溯源原则，全局适用）

一切派生结果（掌握度/归因/报告）记录产生它时的：
知识库版本 + 标注版本 + 算法版本 + prompt 版本。
知识库修订不做隐式迁移，历史数据可追溯、可显式重算。

### 运行时编辑（导入后可改，kb-edit v0.2）

导入后全平台可查看与编辑知识库（前端 `/kb` 页），不依赖改 YAML 重导：

- **属性微调**：name/description/chapter/cog_levels/mastery_floor/difficulty_prior/semester 可改，留痕 CorrectionLog；**code 不可改**（稳定标识 + YAML 幂等匹配键，改 code 走导出->改->新版本导入）。
- **高杠杆参数预览**：改 mastery_floor/difficulty_prior 是"参数即结论"的高杠杆操作（derive-on-read 即时翻转薄弱判定）。PATCH 支持 `?preview=true` 干跑，返回"当前 N 人薄弱 -> 改后 M 人（Δ）"，教师确认后才落库。
- **软归档**（`archived`）：分析层排除（`grade7_kp_ids` 不含 archived），不删行，历史证据按主键可回查。被题目标注的 kp 归档需二次确认（防题目标注静默失效），归档即清教学进度残留。硬删（`force=true`）仅当无证据、无题目标注时，级联删关系与进度。容器节点（C* 前缀）禁删/禁归档。
- **关系 CRUD**：prerequisite/contains/confusable/spiral，端点同版本校验。`kp_relation` 不加 `kb_version_id`，靠端点 kp 隐式归属版本（查询/新建/改都按"端点是否在目标版本 kp 集合"过滤）。
- **版本切换**：fork 当前 active 为草稿 -> 编辑 -> 切 active。切换前两道校验：① code 超集（目标 code ⊇ active，防旧证据静默丢失，缺失可 `force=true` 接受）；② 属性 diff（同 code 的高杠杆参数变化，防参数劣化，需 `confirm=true`）。切换写日志（CorrectionLog），旧 active 降 reviewed 不删可回滚；**切换后新证据不可迁回旧版本**（弹窗明示）。
- **导出**：从 DB 现状生成 YAML（archived 保留），可被 import 读回，作为下次导入基线或结构大改出口。
- **教学进度全管理**：增/删/改 taught_at（原仅增）。archived kp 不允许新标记。

UI 编辑不回写原 YAML；YAML 仅作初始导入与结构大改来源。

## 5. 数据采集层

### 入口优先级（三轮评审后的重排）

| 优先级 | 入口 | 说明 |
|---|---|---|
| P0 | **Excel 成绩单导入** | 教师批改后本就有成绩记录；追踪必需的是每题得分，非图像。零技术风险 |
| P0 | 分数录入表格 | 无 Excel 时的兜底 |
| P1 | 拍照解析 | 增量价值：错题内容、选择题选项（迷思概念分析）、错题本 |

### 两阶段解析（拍照路径）

同一班级考同一张卷，解析拆为两阶段以控制教师审核量：

```
阶段A 试卷模板（每次考试 1 次）：解析题目结构 + LLM 知识点标注 → 教师审核全卷（≈15 分钟）
阶段B 学生卷（每人 1 次）：匹配模板 → 仅抽取每题得分/选项 → 异常才人工复核
```

标注工作量从 `学生数 × 题数` 降为 `题数`。

### 解析流水线要点

- 多模态 LLM 直出结构化 JSON（Schema 强制）；必选字段：题干、题型、满分、每题得分；
  学生手写作答内容为 best-effort 可选项；
- **选择题必须记录所选选项**（不只对错）——干扰项是迷思概念的低成本信号；
- 置信度三级路由：≥0.9 自动通过（可复查）；0.6~0.9 高亮提醒；<0.6 强制人工；
- **PII 剥离前置**：送 LLM 前裁剪/遮盖姓名班级栏，内部只流转学生 ID；
- 原图永久保留（审计 + 模型升级后可重解析）；
- 异步任务工程：队列、重试、断点续跑、成本上限、模型降级；
  解析产物版本化存储（model_version/prompt_version），默认不重跑（LLM 输出非确定）；
- 边界约束写进产品流程：一次上传 = 一名学生一份卷；多页按页码顺序。

### 审核 UX

左图右表审核台；异常式审核（只处理低置信与被标记项）；支持分次审核。
**审核不阻塞初步产出**：允许基于未审数据出"初步报告"（显著标注待审核），
教师时间冲突是真实的（考后最忙），审核异步化、机会化。

### 历史补录（冷启动关键）

首次使用引导教师补录过去 2~3 次考试的成绩存档（Excel），
第一天即呈现纵向趋势——价值即时可见，无需等一学期。

### 证据来源多样化（政策驱动的必需项）

义务教育考试管理可能限制正式纸笔考试频次（每学期 1~2 次）。
系统必须支持多源证据：正式考试 / 单元测 / 课堂练习 / 作业错题 / 诊断题，
不同来源不同权重与衰减（见 §6）。此设计在 MVP 即落实，不是 P2 功能。

## 6. 知识追踪层

### 证据事件（不可变追加）

```
evidence_event:
  student_id, kp_id, 来源题目引用, source_type[考试|练习|诊断|补录],
  value, weight, cog_level, 班级该题平均得分率,
  猜测校正标记, 级联标记, occurred_at, 算法版本
```

**value 计算**：
- 基础值 = 得分/满分，按题内知识点权重 w 分摊（MVP 策略，低置信场景标注）；
- 选择题猜测校正：`e = max(0, (p − g)/(1 − g))`，g = 1/选项数；
- 级联错误降权：解答题前置小题失败导致后续小题连带失分的，
  后续小题证据权重减半并打级联标记；
- 权重按 source_type：考试 > 单元测 > 练习；练习证据额外降权。

### 掌握度推导（derive-on-read）

```
M(s,k,t) = Σⱼ eⱼ · 2^(−Δtⱼ/h) / Σⱼ 2^(−Δtⱼ/h)
```

- 半衰期 h：考试类 60 天，练习类 30 天（可配置）；
- **按认知层级分维**：识记/理解/应用各一条序列（归因"层级断层"的前提）；
- 不存储可变快照；报告导出时物化留档。

### 证据门槛（护栏字段，UI 直接展示）

- 证据题目数 < 3 → 「数据不足」，不参与薄弱判定与归因；
- 最近证据 > 90 天 → 「可能已变化」；
- 教学进度未覆盖的知识点 → 「未学到」，绝不判为薄弱。

### 轨迹形态分类（标量之外的保真）

由证据序列直接分类：`未学到 / 上升 / 下滑 / 稳定 / 震荡`（方差判据）。
掌握度 0.5 的"稳定中等"与"大起大落"归因含义不同，报告同时呈现两者。

### 薄弱判定（双基准）

满足其一即判薄弱（并标注判据类型）：
1. 掌握度 < 绝对底线（默认 0.6，可按知识点配置，基础性知识点可更高）；
2. 掌握度低于班级该知识点分布的 P25（班级参照）。

班级该题平均得分率同时作为免费的客观难度参照；
"教师评定难度档"仅在无班级数据时兜底。

### 异常考试处理

卷面总分相对该生历史骤降 >30% → 标记「疑似异常波动」，证据降权并提示教师确认。

## 7. 归因层

### 假设类型

| 类型 | 判据 | MVP |
|---|---|---|
| 前置缺陷 | 沿前置边下探 ≤3 层，前置点掌握度同步低 | ✅ |
| 遗忘衰减 | 历史掌握度曾高、无练习下持续下降 | ✅ |
| 迷思概念 | 同一干扰项被反复选择（依赖选项数据） | P1 |
| 认知层级断层 | 低层级证据好、高层级证据差（依赖分维掌握度） | P1 |
| 熟练度不足 | 近期证据方差大（时对时错） | P1 |
| 题型陌生 | 某题型专项失分 | P2 |
| 共性因素 | 薄弱点聚类无公共前置祖先 → 怀疑横切因素（阅读理解等） | P2 |
| 数据不足 | 证据低于门槛 → 明示不判断 | ✅ |

### 归因的三条纪律

1. **可证伪**：每条归因生成时附带预测
   （"若是前置缺陷，该前置点的独立诊断题也应失败"），
   诊断小测是证伪手段；归因 = 假设-验证循环，不是结论；
2. **班级参照**：个人弱而班级强 → 学生侧方案；全班弱 → 转为给教师的教学建议，
   不向学生归责；
3. **稳定性**：归因展示需满足证据稳定要求（迟滞），避免结论周周翻转。

### 教师否决权

教师可覆盖任何归因（附注理由），覆盖记录回流为训练/审计信号。

## 8. 干预层

### 设计原则

- **规则驱动决策，LLM 负责渲染**（决策可审计）；
- **Just-in-time 优先**：优先补"正在教的内容的前置缺口"（联动教学进度），
  历史缺口排序靠后；
- **最近发展区**：练习目标正确率 70%~85%，掺入学生当前水平可完成的题，
  避免纯挫败式补差；
- **双重负担控制**：周任务总量预算；方案标注与日常作业的关系。

### 题目来源：题库复用飞轮（干预层的内容基础）

- 每道审核入库的题目自动进题库；
- 干预内容 = 学生自己的错题重做/变式 + 题库中同知识点、同难度、未做过的题；
- **题族（family）**：同结构变式题归族，练习从族中抽取，防止"背题"假会；
- LLM 生成变式题（换数字换情境、结构不变）必须教师审核后入库。

### 方案结构与闭环

```
方案 → 诊断(可选) → 补学 → 练习 → 复测 → 前后掌握度对比回流
```

- `plan_item` 状态机：已布置 / 已完成 / 已逾期 / 已复测；
- 完成度由教师确认（无自动渠道时）；完成度是效果归因的必要协变量
  （未提升 = 归因错 or 没做，需区分）；
- 复测结果同时验证归因预测（§7 纪律 1）。

### 班级层干预

班级共性薄弱点 → 教学建议（重讲/变式训练），进入质量分析文档。
教师的最小工作单元是班级，班级层干预优先于个体方案落地。

## 9. 产品形态

### 交付物优先，仪表盘靠后

教师真实工作物是**文档**（交教务、家长会、讲评课）。第一产品形态：

1. **一键考后质量分析文档**（班级，可编辑、可导出）——替代教师已有工作；
2. **个人诊断单**（薄弱点+证据+建议）；
3. 仪表盘为探索性辅助（班级热力图、学生画像、方案中心）。

### 价值兑现顺序（信任阶梯）

班级共性薄弱点（明天讲评课就能用）→ 个体薄弱清单 → 归因链。
先兑现最容易见效的层，用挣来的信任换深层功能的试错空间。

### 信任防御

- 每条结论证据可点开、置信度可见；
- 对外文档（家长会材料）有"教师预览确认"环节；
- 措辞无绝对化表达；成长框架呈现：先进步、后缺口，缺口表述为"下一步"；
- 禁止排名展示（亦呼应双减要求）。

### 首次使用动线

选学科/年级/教材版本 → 加载预建知识库 → **补录历史考试（2~3 次）**
→ 立即获得纵向趋势与班级诊断 → 此后按考试节奏滚动使用。

## 12. 度量与验证体系

### 北极星指标

**干预提升率** = 被干预薄弱点中，复测后掌握度提升超阈值（如 +0.15）的比例。
从第一批干预开始埋点；这是"确实有效"的唯一终审指标。

### 效果验证：学生内对照

每个学生有多个薄弱点，受精力限制仅干预其中一部分。
比较同一学生**被干预薄弱点 vs 未被干预薄弱点**的提升率差异，
构成零成本的准因果证据。

### 过程指标

- 教师审核单卷耗时（目标：Excel 路径 <15 分钟/班，拍照路径 <3 小时/班）
- 标注修正率（LLM 标注被教师修改的比例，按题型/知识点监控）
- 归因教师认可率（盲测 ≥70% 为 MVP 生死线）
- 解析字段级准确率、单卷 LLM 成本

### 系统自验证（真实数据到来之前就要能推进）

1. **合成学生模拟器**：生成植入已知真值薄弱点/归因的虚拟学生，
   灌入模拟考试数据，断言系统正确还原——归因逻辑的端到端测试，
   真实数据到来后转为回归测试；
2. **金标集**：人工转录 20~30 份试卷（解析金标）+ 人工标注 200 题（标注金标），
   每次换模型/改 prompt 必跑，防静默退化；
3. **预测回测**（P2）：用 t 时刻掌握度预测 t+1 表现，预测准确率为内部质量指标。

## 13. 合规与伦理

- **PII 剥离**：送云端 LLM 前去除姓名/班级等可识别信息，内部只流转学生 ID；
  - **批量录入例外（v0.3）**：批量拍照录入路径为与名单匹配需读取卷面姓名，**定向取消该路径的姓名栏遮罩**；
    约束——姓名仅用于名单匹配、不进入任何报告/判分/额外字段，prompt 铁律限定"姓名仅用于匹配、不得输出其他 PII、不影响判分"；
    `parse_batch_item.detected_name` 设留存边界（matched/duplicate/discarded/指派后即置 NULL，warnings 不内嵌原始姓名）；
    单张拍照路径仍保持遮罩不变。
- **监护人同意**：不满 14 周岁学生信息属敏感个人信息（PIPL），
  试点进校需监护人知情同意流程，纳入试点方案而非上线前补办；
- **双减合规**：不设排名功能；核实当地考试频次规定并据此校准数据量假设；
- **手写质量偏差**：字迹潦草学生（常恰是学困生）解析错误率更高，
  需按学生监控修正率、异常者人工兜底；两阶段设计依赖教师红笔分数，风险已部分缓解；
- **数据生命周期**：毕业/转学的保留与删除策略、家长导出权（P2 前定案）；
- **呈现伦理**：成长框架表述，避免标签效应。

## 14. MVP 范围

### 做（P0）

- 单科单年级知识库（YAML，含跨年级前置边）
- Excel 导入 + 分数录入 + 历史补录
- 证据事件 → 掌握度推导 → 双基准薄弱判定（含证据门槛、轨迹分类）
- 前置缺陷 + 遗忘衰减两类归因（含班级参照、教师否决）
- 一键考后质量分析文档 + 个人诊断单
- 合成数据模拟器 + 金标集 v0

### 明确不做（MVP 之外）

- 拍照解析与审核台（P1）
- 多学科、学生/家长端
- IRT / DKT / 深度模型
- 未经审核的 LLM 出题直达学生
- 账号权限体系、多租户逻辑（仅预留字段）
- 排名类功能（合规禁止）

### MVP 成功标准

1. 教师使用 Excel 路径跑通一次完整考后分析，班级路径总耗时可接受；
2. 归因盲测教师认可率 ≥ 70%；
3. 一名学生补录 + 新增共 ≥ 4 次考试数据，呈现可见掌握度曲线；
4. 合成数据模拟器断言全部通过。
