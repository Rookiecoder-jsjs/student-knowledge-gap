# 多年级演示数据

本项目提供一套可重复执行的本地演示数据，用来展示“同一班级多学科、多个年级、知识图谱按年级切换”的产品流程。数据脚本不会删除已有库，只会补齐演示版本（`demo-2026.09`）和一场阶段测评。

## 覆盖范围

- 七、八、九年级
- 数学、语文、英语
- 每个年级 2 个班；新建演示班级各 12 名学生（已有班级名单保持不变）
- 每个“班级 × 学科”有一场阶段测评、教学进度和可视化掌握度
- 每个学科×年级知识库包含章节容器、知识点、前置关系和少量易混关系

同一班级在数据库中按“班级 × 学科”建模，班级概览页会把它们合并为一个班级卡片，再从学科入口进入对应工作台。

## 生成方式

本地运行：

```bash
cd backend
python scripts/seed_multigrade_demo.py
```

Docker 运行：

```bash
docker exec deploy-backend-1 python /app/scripts/seed_multigrade_demo.py
```

脚本是幂等的，可重复运行；它不会重置数据库，也不会触碰非演示版本。

## 课程资料依据

知识主题按公开课程资料整理，具体学校教材、章节顺序和教学进度仍应由教研组审核：

- [教育部：义务教育课程方案和课程标准（2022 年版）](https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)
- [教育部：义务教育数学课程标准（2022 年版）](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220510531636118932.pdf)
- [人民教育出版社：数学·七年级上册目录](https://www.pep.com.cn/products/jc/czjks/201510/t20151026_1250813.shtml)
- [人民教育出版社：数学八年级上册教材介绍](https://www.pep.com.cn/products/jc/jks/201602/t20160219_1258155.shtml)

语文和英语部分采用课标主题与语言能力维度组织为“演示目录”，没有把演示数据当作正式教材版本。
